## ✨ Overview

**Ever After** is a modern, elegant wedding invitation website designed to present a couple's special day through a refined digital experience.

The project combines thoughtful typography, sophisticated styling, and a responsive page layout to create an invitation that feels personal, memorable, and easy to explore across desktop, tablet, and mobile devices.

Built with semantic HTML5 and modern CSS3, this project demonstrates front-end development skills through a polished, visually focused design.

## 🎯 Project Objectives

- Create a premium digital wedding invitation.
- Present wedding details in a clear and elegant format.
- Apply responsive design principles across different screen sizes.
- Practise semantic HTML, reusable CSS patterns, and accessible interface design.
- Build a portfolio-ready project suitable for showcasing front-end development skills.

## 🌟 Features

- **Elegant visual design** — a refined aesthetic suitable for a wedding celebration.
- **Invitation hero section** — a prominent introduction to the event.
- **Personalised invitation** — uses Stephen Oyugi as the sample invited guest.
- **Wedding details** — a dedicated area for the date, venue, and schedule.
- **Responsive layout** — adapts to desktop, tablet, and mobile screens.
- **Modern typography** — carefully selected type styles for a polished appearance.
- **Structured content** — clear sections and visual hierarchy.
- **Maintainable code** — HTML structure and CSS presentation are separated.
- **Lightweight implementation** — no front-end framework is required.

## 🚀 Getting Started

### Prerequisites

You will need:

- A modern web browser.
- [Visual Studio Code](https://code.visualstudio.com/) or another code editor.
- [Git](https://git-scm.com/) for version control, if you plan to push changes to GitHub.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Regalson001/Ever-After-Wedding-Invitation.git
   ```

2. Open the project folder:

   ```bash
   cd Ever-After-Wedding-Invitation
   ```

3. Open `index.html` in your browser, or open the folder in Visual Studio Code and use the Live Server extension.

## ⚙️ Customisation

You can personalise the invitation by editing `index.html` and `style.css`.

1. Replace the sample guest name, Stephen Oyugi, if required.
2. Add the couple's names and wedding message.
3. Enter the confirmed wedding date, time, and venue.
4. Update the colour palette, fonts, and decorative details.
5. Add suitable wedding photography or imagery.
6. Verify all event information before sharing the invitation.

**Note:** Names and event details should be treated as sample content until confirmed by the couple.

## ♿ Accessibility and Responsive Design

The project aims to follow front-end best practices, including:

- Semantic HTML elements.
- Readable text and clear heading hierarchy.
- Appropriate contrast between text and backgrounds.
- Responsive layouts for smaller screens.
- Meaningful link text and alternative text for informative images.

Accessibility should be verified against the final implementation before the website is published.
